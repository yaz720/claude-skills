# rx-scout(问药)

> **状态:✅ 可用**(触发基线 7 轮快照 83/84、负例全过;能力基线 3 遍:类内选药 21/21、病症选类 16/18,达标线 0.9/0.8 均过,详见 `evals/RESULTS.md`)

一个 Claude Code **技能**:把「该用什么药」变成一份能带去和医生讨论的**选药功课**。覆盖处方药 (Rx) 与非处方药 (OTC),与 care-scout(寻医)组成"寻医问药"配对。

裸问模型"哪种药好",你会得到最流行的两三种药的泛泛对比。装了这个技能,你得到的是模型默认不会做全的那部分:

- **类内全员盘点**——该类每一个已批准成员+撤市史,最适合你的常常不是最流行的那个
- **固定五维横向对比**——效力、代谢与相互作用、半衰期与服药时机、副作用谱(附真实发生率,对抗网络恐慌化)、特殊人群证据
- **族裔证据加权**——亚洲人药代浓度差异、东亚临床试验的对口程度,这一步常会翻转欧美视角下的默认结论
- **画像驱动三档筛选**——明确排除/有条件考虑/重点候选,排除的也给理由,候选逐条对照你的需求清单
- **最低有效剂量与联用预案**——剂量边际递减规律,加量不如联用的决策逻辑
- **就诊讨论问题清单**——把需要医生裁决的点写成可以直接带进诊室的问题

支持四种进入场景:只知道病症(先选类再选药)、已知类别(核心场景)、医生已给几个方案(对比裁决)、已在用药(评估调整空间)。

## 边界

- 产出是**调研功课,不是处方**:用药的开始、停止、剂量调整永远交给医生决定
- 该不该治疗/要不要手术的多学科分析 → second-opinion-panel
- 营养补充剂选购 → supplement-scout
- 找医生、该看什么科 → care-scout
