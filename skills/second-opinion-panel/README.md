# 圆桌会诊 (second-opinion-panel)

> **状态:🚧 开发中**(触发基线 22/23、负例全过,失败的 trig-006 经复采样核验为裁判抖动而非真回归;
> 4 条能力用例已写好、尚未实跑判分,补齐后再转 ✅)

一个 Claude Code **技能**:**组织一场多学科会诊(MDT)——遴选 4-6 位不同立场的专家,主持三轮结构化辩论,产出中英双语会诊报告。**

定位要说在前面:**这不是诊断,是帮你把一次真实门诊的 15 分钟用到极致的准备材料。**

## 为什么需要它

单一视角的医学分析有个固有缺陷:一旦选定某个诊断框架,后面所有推理都会为它服务。

多角色讨论理论上能纠正这一点,但如果设计不当,会退化成几个人轮流点头——**那比单一视角更危险**,因为它披上了「多方一致」的外衣。所以这个技能的核心不是「扮演几个医生」,而是**用制度化的对抗防止过早收敛**。产物不是一个答案,而是一张地图:哪些是共识、哪些仍在争议、争议需要什么信息才能裁决。

## 六个阶段

```
阶段 0  红旗筛查      → 有急症信号则中止,直接指向急诊
阶段 1  病例梳理      → 提炼事实、标注缺口、声明假设
阶段 2  证据检索      → 强制联网查最新指南,梳理沿革与推翻关系
阶段 3  组阁          → 按规则遴选 4-6 位专家
阶段 4  三轮辩论      → 独立陈述 → 交叉质证 → 收敛定位
阶段 5  双语报告      → 中英两份 Markdown 真文件
```

## 防「假共识」的几个装置

技能的价值几乎全在这些机制上——它们正是"让几个 AI 医生聊一聊"最容易缺的东西。

- **常驻对抗席**:立场必须与主诊专科**相反**。专科主张保守,他就论证干预;专科主张干预,他就论证观察。不因为"专科说得有道理"就省掉
- **第一轮互不参照**:不许出现「如上所述」「正如某某所说」,防第一个发言者定调
- **第二轮必须点名质疑**:禁止「我基本同意大家的看法」这类发言;认同也必须找出该主张的边界条件
- **论据台账 + 结算**:对抗席第一轮**穷举**所有反对理由并标强弱(强/中/弱),第三轮逐条给状态(成立/被限定/被驳倒)。**被驳倒的论据连同驳倒理由一起保留在报告里**——你日后会在网络、亲友、别的医生那里再遇到这些论点,写着"这条检验过了、被 X 以 Y 理由驳倒"远比让它悄悄消失有用
- **同数据反向解读标注**:同一组数据被两方用来支持相反结论时单独标出,说明分歧不在事实层面而在解读框架
- **全体一致则强制写《反对意见备忘》**:真实 MDT 里全票通过是罕见的,轻易达成一致更可能是角色设计得不够独立
- **共识为「不干预」时不生成治疗方案对比表**:罗列术式本身会产生锚定效应,选项清单从来不是中性的

## 证据这块的硬规矩

- **每次会诊强制联网**,不许只凭已有知识讨论
- 必须交付**证据沿革**表:旧做法为什么被认为有问题、新证据揭示了什么、这个转变是否已被广泛接受
- **证据分级 A/B/C/D 如实标注**:中医和功能医学的建议大量落在 C/D 级——这不代表无效,但不能把动物实验说得像 RCT;西医某些常规做法也可能只有 C 级,同样照实标
- **反捏造铁律**:只引用实际读到的来源;不编造研究名称、样本量、p 值、指南条款编号;检索不到就写"未检索到明确证据"

## 双语报告

中英两份**独立的 Markdown 真文件**,内容等价(不是摘要与全文的关系)。中文版专业名词首次出现附英文原词;英文版的中医概念给**拼音 + 汉字、不做意译**——`qi deficiency (气虚, qì xū)`,因为直译成 "energy deficiency" 会让外国医生完全误解,拼音加汉字反而能让对方查证。

## 硬约束

写进每份报告页脚:这是讨论材料**不是诊断**,所有"专家"均为角色模拟;不给个体化处方剂量;不编造证据;**不强行拼共识**(无定论就写无定论,并说明分歧性质);不替代急诊判断;涉及未成年人、孕产妇、老年人、器官功能不全者额外标注特殊人群警示。
