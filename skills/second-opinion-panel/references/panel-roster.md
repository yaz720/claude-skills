## 遴选逻辑

先问三个问题，再选人：

1. **这个病的主战场在哪个系统？** → 决定主诊专科
2. **对这个病最主要的临床争议是什么？** → 决定对抗席的立场
3. **除了"治不治"，这个人还有什么需要被照顾的？** → 决定执行角色

如果三个问题里有一个答不上来，说明阶段 1 的病例梳理做得不够，回去补。

## 主诉 → 主诊专科对照

| 主诉领域 | 主诊专科 | 常见搭配 |
|---|---|---|
| 关节/脊柱/肌肉疼痛 | 风湿免疫科 或 骨科 | 康复科、疼痛科 |
| 血管、肢体循环 | 血管外科 | 介入放射、血液科 |
| 消化道症状 | 消化内科 | 营养师、感染科（幽门螺杆菌） |
| 心悸、胸闷、血压 | 心内科 | 内分泌、睡眠专科 |
| 疲劳、体重变化、月经异常 | 内分泌科 | 妇科、血液科 |
| 皮肤病变 | 皮肤科 | 变态反应科、风湿免疫 |
| 头痛、麻木、无力 | 神经内科 | 影像科、康复科 |
| 反复感染 | 感染科 | 免疫科 |
| 呼吸道症状 | 呼吸科 | 变态反应科、耳鼻喉 |
| 情绪、睡眠、注意力 | 精神心理科 | 睡眠专科、内分泌 |
| 儿童生长发育 | 儿科 | 儿童内分泌、营养师 |
| 骨密度、骨折风险 | 内分泌/骨代谢 | 老年科、康复科 |
| 泌尿、生殖 | 泌尿外科/妇科 | 内分泌 |
| 肿瘤相关 | 肿瘤科 | 病理科、姑息治疗、营养师 |

**影像科医师**是一个被低估的席位。凡涉及 MRI、CT、超声报告解读，请一位影像科专家能纠正很多误读——报告措辞（"考虑""不除外""建议随访"）背后的确定性差异很大，临床医生和患者常常读错。

## 对抗席怎么选

对抗席的任务是**论证主诊专科的对立面**，不是抬杠。选择逻辑：

| 主诊专科的倾向 | 对抗席人选 | 攻击方向 |
|---|---|---|
| 主张手术/介入 | 保守治疗专科、康复科、循证医学专家 | 手术指征是否成立、自然病程、过度治疗风险 |
| 主张保守观察 | 更激进的专科医生 | 观察期间的进展风险、错过治疗窗口 |
| 主张长期用药 | 临床药师、老年医学 | 副作用累积、多重用药、停药策略 |
| 主张某个诊断 | 另一诊断方向的专科 | 鉴别诊断被忽略了什么 |
| 依赖某项检查结果 | 临床流行病学/循证医学 | 检查的敏感性特异性、假阳性率、预测值 |
| 强调罕见病可能 | 全科医生 | "听到蹄声先想马"、检查级联的代价 |

**循证医学 / 临床流行病学专家**是万能对抗席。他不站在任何治疗立场上，只攻击证据本身：样本人群和本例像不像？终点指标是替代终点还是硬终点？绝对风险下降有多少（不是相对风险）？NNT 是多少？

## 平行体系席位

### 中医

纳入时机：慢性病、功能性症状、西医查无异常但确有不适、术后/病后调理、用户明确要求。

**要求做独立病机推演**，而不是把西医诊断翻译成中医词汇。糟糕的示范是"高血压属于中医肝阳上亢"——这是贴标签。好的示范是从患者的具体症状、体质、诱因、病程演变推出病机，再定治法。

发言要素：病名归属（古称）、病机分析、证型判断、治法、方向性方剂、外治法、调摄建议、以及**明确说出中医在这个病上做不到什么**。

### 整合医学 / 功能医学

纳入时机：多系统症状、代谢问题、慢性炎症、自身免疫、"查不出病但很难受"、想理解上游原因。

核心问题是**"为什么是这个人，在这个时候，得这个病"**。关注上游机制：肠道屏障、微生物组、营养素状态、毒物暴露、慢性压力、睡眠、血糖调节、线粒体功能。

**必须自我约束**：这个领域商业化程度高、检测项目繁多、证据参差。要求这个席位主动说明哪些建议有真实证据、哪些是机制推测、哪些检测性价比低不推荐做。

## 执行角色席位

这些席位**不参与"是什么病"的辩论**，只在第二、三轮回答"这个方案实际做得到吗"。

| 角色 | 纳入时机 | 关注点 |
|---|---|---|
| 临床营养师 | 涉及饮食干预、体重、代谢、消化 | 实际可执行性、文化饮食习惯、营养素缺口、极端饮食风险 |
| 康复治疗师 | 涉及疼痛、运动功能、姿势、术后 | 动作模式、渐进负荷、代偿、家庭训练依从性 |
| 临床药师 | 多药联用、老年人、肝肾功能不全 | 相互作用、剂量调整、副作用监测、减停策略 |
| 心理/精神科 | 慢性病心理负担、躯体化、依从性差 | 疾病焦虑、行为改变的心理障碍、医患沟通 |
| 睡眠专科 | 疲劳、代谢、疼痛、情绪问题 | 睡眠呼吸暂停常被漏诊，是多种问题的上游 |
| 疼痛管理 | 慢性疼痛 | 中枢敏化、镇痛阶梯、非药物手段 |
| 姑息/安宁疗护 | 晚期疾病、高龄、生活质量优先 | 治疗目标是延长生存还是改善质量 |

## 常见组阁范例

**慢性腰背痛，年轻人**
风湿免疫科（主诊）· 骨科/脊柱外科（对抗席，主张影像和结构问题）· 家庭医生 · 康复治疗师 · 中医

**中年女性疲劳、体重上升、怕冷**
内分泌科（主诊）· 循证医学专家（对抗席，质疑亚临床甲减是否需治疗）· 家庭医生 · 睡眠专科 · 整合医学 · 营养师
→ 已达 6 人上限，需要取舍

**老年人多种慢性病、用药十余种**
老年医学科（主诊）· 临床药师（对抗席，主张减药）· 家庭医生 · 相关专科 1 位 · 营养师

**儿童反复呼吸道感染**
儿科（主诊）· 免疫科（对抗席，主张排查免疫缺陷）· 家庭医生 · 中医（儿科调理有传统优势）· 变态反应科

## 组阁反模式

以下做法会让会诊失效：

- **凑数式组阁** — 请了六个人但三个人观点雷同。宁可四个人，每人视角真正不同
- **没有对抗席** — 全场只有程度差异，没有方向分歧
- **中医席位当翻译** — 只是把西医结论换成中医词汇，没有独立推演
- **执行角色越位** — 营养师去辩论诊断，失去了"落地检验"的功能
- **专科过度细分** — 请了三个亚专科，都在同一个框架内争论细节，看不到框架外的可能
- **忘了全科** — 没人从"这个人整体过得好不好"和"有必要查这么多吗"的角度发言
