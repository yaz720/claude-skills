# 评价交叉解读方法论(Yelp × Google × 其他)

服务业评价的通病:样本小、两极分化、有刷评动机。本文回答三个问题:
两平台各信几分?怎么识别刷评?负评怎么归类才有用?

## 一、两平台机制差异(为什么不能混着看)

| | Google Maps | Yelp |
|---|---|---|
| 样本量 | 通常大 2-5 倍(留评门槛低) | 小,但单条信息量大 |
| 过滤机制 | 几乎不过滤 | **有推荐算法**,会把新账号/低活跃用户的评价压进 "not recommended",商家喊冤最多的也是这里 |
| 刷评难度 | 低(买好评产业链主打 Google) | 相对高(过滤器会吞掉一批) |
| 文字质量 | 短评多、"Good service" 式空评多 | 长文多、细节多、差评尤其详细 |
| 用户群 | 全体 | 偏城市、偏爱写评价的人群,差评倾向略高 |
| 商家操纵手法 | 刷好评、求好评换折扣 | 施压删差评、在 "not recommended" 里藏差评 |

**用法:**
- 两平台分数**并列呈现**,不平均。分差 ≥ 0.7 星就点明并给出解释假设
  (常见:Google 被刷高了 / Yelp 被过滤后剩下的极端化)。
- Yelp 的 **"not recommended" 评价也要翻**(页面底部灰色链接):它不计入星级,
  但里面常有真实差评;同样也有真实好评被误杀。当补充证据用,别当主证据。
- 第三平台按行业补:驾校/教学看 Google 为主;搬家看 Yelp + BBB;修车看 Yelp +
  RepairPal/Carfax 认证;装修看 Yelp + Nextdoor + Houzz;华人服务商加搜中文社区
  (一亩三分地、本地华人论坛/公众号)。

## 二、刷评识别信号(逐条看时过一遍)

单条信号都不定罪,**三条以上叠加**才降权:

1. **时间爆发**:短期内密集涌入一批 5 星(按时间排序看分布)——尤其出现在一条恶性差评之后,是"稀释差评"的典型手法
2. **空泛通稿**:只有 "Great service! Highly recommend!" 没有任何具体细节(什么服务、谁接待、多少钱)
3. **评价者画像**:该账号只评过这一家,或评过的商家横跨多州
4. **文风雷同**:多条评价句式相似、都提同一个营销卖点
5. **好评提人名率异常**:真实好评常自然提到具体的人和事;刷评只夸店

**反向也成立**:恶意差评(同行攻击、一次纠纷刷十条)同样识别——同一事件多账号复述、
细节对不上、只有情绪没有事实。

## 三、星级怎么用,文字怎么用

- **星级 = 粗筛**:3.5 星以下且样本 ≥ 30 直接淘汰(除非用户预算极端敏感);
  4.0-4.4 与 4.5+ 之间**不要机械分高下**——样本 15 条的 4.8 不如样本 200 条的 4.3 可信。
- **小样本(<20 条)**:星级基本无统计意义,直接进文字层,并向用户明说"样本小,分数仅供参考"。
- **3 星评价优先读**:动机最干净(没爱没恨),通常优缺点并陈,是判断"这家到底什么水平"的最短路径。
- **最新 10 条单独看**:服务业换老板/换师傅后口碑会断崖,三年前的 5 星救不了上个月的连环差评。
  发现**近期口碑与历史口碑背离**,以近期为准,并提醒用户"可能换过人/易主"。

## 四、负面评价主题归类(呈现时必须单列)

按下面五类归,统计各类出现次数:

| 主题 | 典型表述 | 权重判断 |
|---|---|---|
| 💰 收费不透明/隐性加价 | "报价 X 最后收 Y"、"没提前说要收" | **最高权重**——直接伤钱,且是模式性行为 |
| 📅 爽约改约/放鸽子 | "临时取消"、"迟到一小时"、"约不上" | 教学类高权重(拖课时),一次性服务中权重 |
| 😠 态度差/不耐烦 | "凶人"、"rude"、"被吼" | 教学类高权重(影响学习效果),维修类低权重 |
| 🔧 结果差/技术差 | "没修好"、"考了三次没过"、"墙裂了" | 高权重,但先排除用户自身因素的个案 |
| 👻 售后失联 | "出问题就不回消息"、"保修是空话" | 装修/维修类最高权重 |

归类后必答两个区分:
- **偶发 vs 模式**:同主题 ≥ 3 条不同时期的评价 = 模式,必须报告;只有 1 条 = 记为偶发,轻提
- **针对个人 vs 针对机构**:教学类尤其重要——"避开 A 教练、指名 B 教练"是比"换一家"更优的建议;
  商家对差评的**回应风格**(道歉解决 vs 阴阳怪气反咬)本身就是判断材料

## 五、呈现模板

```
【XX 驾校】Google 4.6(212 条)| Yelp 3.9(48 条,另有 not-recommended 17 条)
分差说明:Yelp 差评集中在 2023 年前台改约问题,近一年已少见
✅ 正面:多条点名教练 Ken 对紧张学员耐心;中文沟通顺畅(6 条中文评价)
⚠️ 负面(模式):按小时售课、多条反映"教练暗示多买课时"(💰,4 条,2022-2025 持续)
⚠️ 负面(偶发):1 条投诉迟到
🚩 需电话确认:官网价格页 2024 年未更新
```
