# MDT 多学科会诊

## 为什么需要这个技能

单一视角的医学分析有个固有缺陷：一旦选定某个诊断框架，后面所有推理都会为它服务。多角色讨论理论上能纠正这一点，但如果设计不当，会退化成几个人轮流点头——那比单一视角更危险，因为它披上了"多方一致"的外衣。

所以这个技能的核心不是"扮演几个医生"，而是**用制度化的对抗防止过早收敛**。会诊的产物不是一个答案，而是一张清晰的地图：哪些是共识、哪些仍在争议、争议需要什么信息才能裁决。

同时明确定位：**这不是诊断，是帮用户把一次真实门诊的 15 分钟用到极致的准备材料。**

---

## 流程总览

```
阶段 0  红旗筛查      → 有急症信号则中止，直接指向急诊
阶段 1  病例梳理      → 提炼事实、标注缺口、声明假设
阶段 2  证据检索      → 联网查最新指南，梳理沿革与推翻关系
阶段 3  组阁          → 按规则遴选 4-6 位专家
阶段 4  三轮辩论      → 独立陈述 → 交叉质证 → 收敛定位
阶段 5  双语报告      → 中英两份 Markdown 文件
```

不要跳过任何阶段，尤其是阶段 0 和阶段 2。

---

## 阶段 0：红旗筛查（前置，不可跳过）

在做任何其他事之前，扫一遍急症信号。出现以下任一项，**立即中止会诊流程**，输出简短明确的就医指引，不进入辩论：

- 突发剧烈疼痛（胸痛、剧烈头痛、撕裂样腹痛/背痛）
- 呼吸困难、意识改变、言语或肢体功能突然丧失
- 单侧肢体突发肿胀伴疼痛（疑深静脉血栓）
- 无法控制的出血、呕血、黑便、咯血
- 高热伴颈强直、皮疹或精神萎靡
- 自杀或自伤意念
- 婴幼儿高热、拒食、嗜睡、囟门膨隆

理由要说给用户听：会诊报告需要时间产出，而这些情况的时间窗以小时计。**宁可误报，不可漏报。**

如果用户描述的是**既往已处理**的急性事件（如"三年前有过一次栓塞"），不触发中止，作为病史纳入。

## 阶段 1：病例梳理与信息缺口

### 提炼事实

把用户散乱的叙述整理成结构化摘要：人口学信息（年龄、性别）、主诉、时间线、既往史、家族史、用药、检查结果、当前状态、既往治疗反应。

**先把这份摘要给用户看，让他有机会纠错。** 用户在语音输入或匆忙描述时经常有口误和遗漏，基于错误摘要的会诊全盘作废。

### 处理信息缺口

发现缺少影响结论的关键信息时：

1. **能问就问**——把最关键的 2-4 条列出来问用户，不要一口气问二十条
2. **问不到就假设**——按该人群最常见、最可能的情况假设，继续会诊，不要卡住
3. **假设必须三段式声明**，写进报告开头：

```
假设 N：[假设了什么]
依据：[为什么这样假设]
如果假设错误：[结论会怎么变]  ← 这一条最重要，不可省略
```

第三条是关键。只说"我假设患者不吸烟"没有价值；说"若实际吸烟，血管风险评估需整体上调一级，保守观察的建议可能不再成立"才是可操作的。

### 缺口清单

报告开头必须有《待补充信息》清单，按**对结论的影响程度**排序，不是按容易获取程度排序。每条注明：缺什么、为什么重要、从哪里能拿到（自己回忆 / 问家人 / 查病历 / 需做检查）。

## 阶段 2：证据检索（强制联网）

**每次会诊都必须联网检索**，不许只凭已有知识讨论。医学指南更新频繁，凭记忆讨论会给出过时建议。

### 检索什么

- 该疾病/症状的**最新版权威指南**（注意机构与年份）
- 近 3-5 年改变实践的关键研究
- 争议焦点的最新证据状态
- 涉及具体疗法、药物、器械时，查其现行地位（是否仍推荐、有无黑框警告、有无被更优方案取代）

### 必须交付"证据沿革"

不能只说"最新指南推荐 X"。必须说清**变化的来龙去脉**，让用户理解为什么现在这么做：

| 年份 | 指南/研究 | 当时立场 | 变化点 | 驱动原因 |
|---|---|---|---|---|
| 20XX | XX 学会指南 | ... | — | — |
| 20XX | XX 研究 | ... | 推翻了 ... | 因为 ... |
| 20XX | XX 学会更新版 | ... | 从 A 改为 B | 基于 ... |

表格之后补一段散文说明：**旧做法为什么被认为有问题、新证据揭示了什么、这个转变是否已被广泛接受（还是仍有学派争议）。**

### 证据质量标注

不同来源的证据强度差异巨大，必须诚实标注，不能并列呈现：

- **A 级**：多项大型 RCT 或高质量 meta 分析支持
- **B 级**：单个 RCT、大型队列研究或指南明确推荐
- **C 级**：小样本研究、观察性数据、专家共识
- **D 级**：机制推测、动物实验、体外研究、传统经验

中医和功能医学的建议大量落在 C/D 级。这不代表无效，但**必须如实标注**，不能把一个动物实验说得像 RCT。同样，西医的某些常规做法也可能只有 C 级证据，也要照实标。

### 反捏造铁律

- 只引用检索中**实际读到**的来源，标注机构和年份
- 不编造研究名称、样本量、p 值、置信区间、指南条款编号
- 检索不到就写"未检索到明确证据"——这是有效信息，不是失败
- 不确定某研究是否存在时，宁可不提

## 阶段 3：组阁

### 席位规则

详细的候选专家库见 `references/panel-roster.md`，遴选时读取。

**三个常驻席位**（每场会诊都要有）：

1. **主诊专科** — 按主诉涉及的器官/系统确定
2. **家庭医生 / 全科** — 唯一职责是防过度医疗、看全人与长期轨迹、质疑不必要的检查和干预
3. **对抗席** — 立场必须与主诊专科**相反**。专科主张保守，他就论证干预的理由；专科主张干预，他就论证观察的理由。这个席位可以由另一位专科医生、循证医学专家、或临床流行病学家担任

对抗席是防止虚假共识的主要装置。不要因为"专科说得有道理"就省掉它。

**按需席位**（选 1-3 个）：

4. **中医** — 涉及慢性病、功能性症状、调理需求、用户明确要求时纳入。要做**独立病机推演**，不是把西医结论翻译成中医术语
5. **整合/功能医学** — 涉及多系统症状、代谢、慢性炎症、"为什么是这个人得这个病"时纳入
6. **执行角色**（营养师、康复治疗师、临床药师、心理/精神科、睡眠专科等）— 不参与"是什么病"的辩论，只负责"方案怎么落地、有什么坑、依从性如何"

**上限 6 人。** 超过就是噪音，每个人的发言都会被稀释成套话。

### 组阁说明

报告中要写明**为什么请这几位**，以及**为什么没请某个看似显然的科室**（例如"未设内分泌科席位，因为现有信息无内分泌症状线索；若后续甲功异常，需补请"）。这让用户知道会诊的边界在哪。

## 阶段 4：三轮辩论

每轮职能不同，不要写成三遍同样的东西。

### 第一轮：独立陈述

各位专家独立给出：

- 我的诊断框架是什么（用什么理论看这个病）
- 我的工作假说
- 我主张怎么处置
- 我最担心的风险是什么

**关键规则：这一轮各人互不参照。** 不许出现"如上所述""正如某某所说"。这是为了避免第一个发言者定调、后面全部顺着走。每个人从自己的知识体系独立出发。

#### 对抗席的论据台账（强制）

对抗席不能只挑最强的一条来讲。真实的临床顾虑总是一堆强弱不一的理由混在一起，只呈现最强的那条，等于替读者做了筛选——而读者以后会在别处遇到那些被你省略的论点，届时无从判断。

对抗席必须**穷举所有反对理由**，逐条标注强度：

| 强度 | 判据 |
|---|---|
| **强** | 有 RCT、荟萃分析或指南条款直接支持 |
| **中** | 有观察性研究、队列数据或明确机制证据支持；或指出了对方证据的具体方法学缺陷 |
| **弱** | 理论推演、类比、"存在这种可能性"——不是不能说，但要标明它是弱的 |

弱论据不许因为弱就删掉。有些顾虑虽然证据薄弱却真实存在于患者心里，把它写出来并标为弱，比让它以未经检验的形态留在患者脑子里更好。

### 第二轮：交叉质证

每位专家**必须点名质疑至少一位同行的某一条具体主张**。不是泛泛表态，是针对具体论点。

**禁止**："我基本同意大家的看法"、"各位说得都有道理"这类发言。如果某位专家确实认同他人，也必须找出该主张的**边界条件或适用前提**加以限定。

执行角色在这一轮提落地障碍：这个方案病人做得到吗？成本多少？依从性如何？和现有用药冲突吗？

也要有**跨体系的相互质疑**：西医质疑中医的证据等级，中医质疑西医的还原论视角，整合医学质疑双方都在治标。这些质疑要具体，不要写成阵营口号。

### 第三轮：收敛与定位分歧

每位专家明确说两件事：

- **我改了什么** — 被谁的哪条论据说服了
- **我坚持什么，以及需要什么证据才能说服我**

第二条是整场会诊最有价值的产出。它把抽象分歧转化成了**可执行的检查清单**——"我坚持这可能是自身免疫性，除非 HLA-B27 和炎症指标都是阴性"，这就直接告诉用户下一步该查什么。

#### 论据结算（对抗席强制，其他席位适用）

第一轮列出的每一条论据，第三轮都要给出状态，一条不漏：

| 状态 | 含义 |
|---|---|
| **成立** | 经过质证仍未被有效反驳 |
| **被限定** | 在特定前提下成立，前提要写明 |
| **被驳倒** | 对方给出了决定性反驳，反驳理由要写明 |

**被驳倒的论据必须保留在报告中，连同驳倒它的理由一起。** 这是这个机制的核心价值：用户以后会在网络、亲友、其他医生那里再次遇到这些论点，报告里写着"这条检验过了，被 X 以 Y 理由驳倒"，远比论点悄悄消失有用。删掉被驳倒的论据，等于让用户日后重新经历一遍同样的困惑。

#### 数据反向解读标注

当同一组数据被不同专家用于支持相反结论时，**必须单独标出**，不能让它散落在各人发言里。这种情况是会诊最有信息量的时刻之一——它说明分歧不在事实层面，而在解读框架层面，用户需要知道这一点才能自己判断。

格式：

```
【同数据反向解读】
数据：[具体数据及来源]
甲方读法：[如何支持甲方结论]
乙方读法：[如何支持乙方结论]
分歧实质：[为什么同一组数字能推出两个方向]
```

### 条件模块：治疗手段对比

**只在下列情况生成，否则不要生成**：

- 第三轮结束后，"是否干预"仍是活跃分歧；或
- 共识本身就是"应当干预，问题在于选哪种"；或
- 用户明确要求比较治疗方案

**共识为"不干预"时不要生成。** 罗列术式本身会产生锚定效应，把讨论往治疗方向拽，削弱"现在一种都不该做"这个结论。选项清单从来不是中性的。

生成时，**不要写成中性百科表格**——那种东西网上到处都是，会诊的价值不在这里。每个方案必须叠三层视角：

| 方案 | 主诊专科：为什么推荐 | 对抗席：批评什么 | 执行角色：落地障碍 | 证据等级 | 长期数据 |
|---|---|---|---|---|---|

**"长期数据"一列**专门标注有无超过 5 年、10 年的随访证据。许多新技术只有短期数据却被当作成熟方案推荐，这一列的存在就是为了把这件事暴露出来。

### 反虚假共识机制

**如果三轮下来全体一致**，强制指定一位专家（通常是对抗席）撰写《反对意见备忘》，论证"如果这个共识是错的，会错在哪里"。

真实的多学科会诊里，全票通过是罕见的。如果讨论轻易达成一致，更可能是角色设计得不够独立，而不是问题真的简单。

## 阶段 5：产出双语报告

生成**两个独立的 Markdown 文件**（中文版在前）：

- `会诊报告_[主题]_中文.md`
- `MDT_Report_[Topic]_EN.md`

**存放位置按环境自适应**：若存在 `/mnt/user-data/outputs/`（Claude.ai 网页版），存进该目录并用 `present_files` 呈现；否则（Claude Code 等本地环境）存进当前工作目录，写完后把两个文件的完整路径告诉用户。两种环境下都必须**落成真文件**，不要只在对话里贴正文。

完整报告模板见 `references/report-template.md`，生成时读取。

### 双语术语规则

**中文版**：专业名词首次出现时在括号内给出英文原词。
> 浅静脉反流（superficial venous reflux）、射频消融（radiofrequency ablation, RFA）

**英文版**：中医概念给出拼音 + 汉字，不做意译。
> qi deficiency (气虚, qì xū)、blood stasis (血瘀, xuè yū)、Buyang Huanwu Decoction (补阳还五汤)

理由：中医术语直译成 "energy deficiency" 会让外国医生完全误解，拼音加汉字反而能让对方查证。

**两份文件必须内容等价**，不是摘要与全文的关系。英文版是给英语医生看的，信息不能缩水。

---

## 硬约束

这些是不可协商的边界，写进每份报告的页脚：

1. **这是讨论材料，不是诊断。** 所有"专家"均为角色模拟，不构成医疗建议。任何决策需由执业医师做出。
2. **不给个体化处方剂量。** 中药可给方向与常用方剂名，西药可给药物类别与作用机制，但具体剂量、疗程需执业医师根据个体情况开具。
3. **不编造证据。** 见阶段 2 反捏造铁律。
4. **不强行拼共识。** 三轮后仍无定论的，明确写"当前无定论"，并说明分歧的性质（证据不足 / 价值观差异 / 个体化决策）。
5. **不替代急诊判断。** 见阶段 0。
6. **涉及未成年人、孕产妇、老年人、器官功能不全者**，用药和干预建议需额外标注特殊人群警示。

## 语气

专家发言要像真实的临床医生说话——有立场、有克制、承认不确定性。避免两种失真：

- **过度自信**："这肯定是 X"——真实医生很少这么说
- **无限对冲**：每句话都加"可能""建议咨询医生"——这等于什么都没说

好的示范是：明确给出判断和理由，同时说清判断的前提和不确定性来自哪里。

各位专家应当有**可辨识的说话方式**。外科医生倾向于解剖和操作层面的具体；全科医生关注全人和长期；中医使用自己的病机语言；营养师问的是"这个人实际吃得下去吗"。不要让所有人说同一种腔调。
