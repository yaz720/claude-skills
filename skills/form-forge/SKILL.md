# form-forge · 练形坊

把「教练教了个动作」变成**一张能用很多年的卡**。

模型不装这个技能也能写一段动作说明，但它写出来的通常是「深蹲要挺胸、别弓背」这种谁都知道的话。
这个技能提供的是模型不会自己做的四件事：

1. **配图流水线** —— 从维基共享资源取版权干净的解剖图，内置一整套踩坑规则（见下）
2. **代偿表** —— 逼着把「做错了**谁在代偿**、你会**感觉到哪儿**、说明**哪块弱**」答完，
   而不是写一句「别耸肩」
3. **一套分类法** —— 三个标签轴 + 训练性质九类 + 肌肉分量三档，让动作之间能互查
4. **两半结构** —— 客观知识共用、各人记录分区，卡越用越厚而不是越用越乱

## 什么时候用我 / 什么时候别用我

**用我**：要给某个动作建卡、要建或维护动作库 / 肌肉名称对照表、要把教练的口头提点记下来、
要更新某人的训练强度、要知道今天这几个动作练到了哪些肌群、要给动作配版权干净的解剖图或自绘示意图。

**别用我**：
- 只是问健身知识、要一份训练计划或课表，**并不打算落盘**成卡 → 直接回答就好
- 算热量、宏量营养素、食谱营养成分 → 那是营养类技能的活
- 找医生、理疗师、康复师 → 那是找医疗从业者的技能
- 单纯要一张流程图 / 数据图表 → 那是画图技能
- 补剂选购调研
- **身上疼、怀疑受伤、要诊断** → 不接。提示去看专业人士，这个技能不做医疗判断

## 第一次用：先问清落位

技能**不预设**任何目录结构、称呼或人数。开工前问用户（或从库里探测后确认）：

1. **动作卡放哪个文件夹**？（比如 `训练/动作库/`）
2. **图片放哪**？（建议卡同级的 `_图/`，肌肉图再分一层 `_图/肌肉/`）
3. **教练怎么称呼**？（真名、代号、还是就叫「教练」；有几位教练要不要指名）
4. **有几个人在练**、怎么称呼？**人数不固定，别写死**，谁练谁开区

把答案记进用户项目的 `CLAUDE.md` 或等价配置，**不要写进本技能**。

## 工作流

### 建卡

1. 用户报动作名（中英文皆可）→ 确认是哪个版本 / 流派，拿不准就问
2. 套 `assets/card-template.md`，按 `references/card-spec.md` 的固定顺序写
3. 配图：先查 `assets/muscles.tsv` 已验证索引，缺的用脚本现搜
   （`references/image-pipeline.md`）
4. 自绘两张示意图（`references/drawing.md`），**渲染后目视检查有没有重叠溢出**
5. 打三个轴的标签（`references/taxonomy.md`），挂进动作库索引页
6. 对照表里没有的肌肉顺手补一行并登记署名
7. 照 `references/card-spec.md` 末尾的自检清单过一遍

### 日常维护

见 `references/logging.md`。要点：**不记训练流水**（教练 app 里有），
只记「怎么做对」和「我被提点过什么」；同一个毛病第二次出现就**主动**提炼进自查清单。

## 边界

- **不是医疗建议，不替代教练。** 每张卡的变式提醒里都写明「以你自己教练的做法为准」
- 涉及疼痛、伤病、康复，提示去看专业人士，不做诊断
- 动作规范各流派有分歧，卡上必须写清写的是哪一版
