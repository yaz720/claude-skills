# 练形坊 (form-forge)

> **状态:🚧 开发中**(触发基线 18/18 通过、负例全过;4 条能力用例已写好、尚未实跑判分,补齐后再转 ✅)

一个 Claude Code **技能**:**把「教练教了个动作」变成一张能用很多年的卡,并落盘进你的笔记库。**

模型不装这个技能也能写一段动作说明,但写出来的通常是「深蹲要挺胸、别弓背」这种谁都知道的话。这个技能提供的是模型**不会自己做**的那几件事:抓版权干净的解剖图、把「做错了谁在代偿」答完整、给动作打上能互查的标签、把教练随口一句提点归档到对的地方。

## 这个技能做什么

- **配图流水线** —— 从维基共享资源(Wikimedia Commons)取**版权干净**的解剖图,内置一整套踩坑规则:拉丁拼法变体重试、尸体照/视频截图的作者黑名单、同名词撞车过滤、42 块肌肉的已验证图源索引、署名登记
- **自绘两张示意图** —— 动作轨迹图 + 发力肌肉图(SVG + PNG,填充轮廓画法,不是火柴棍),渲染后目视检查有没有重叠溢出
- **代偿表(五列)** —— 逼着把「做错了**谁在代偿**、你会**感觉到哪儿**、说明**哪块弱**、怎么改」答完,而不是写一句「别耸肩」
- **一套分类法** —— 三个标签轴 + 训练性质九类 + 肌肉分量三档,让动作之间能互查(「今天这几个动作练到什么肌群、缺了什么」靠它回答)
- **两半结构** —— 客观知识共用、各人记录分区,卡越用越厚而不是越用越乱
- **日常维护** —— 把随口说的教练点评按人按日期归档、更新强度表、同一个毛病第二次出现就**主动**提炼进自查清单

## 最高频的用法

不是建卡,是**归档教练的一句话**。「教练说我某动作哪里不对,记一下」——这句话就该触发它,把提点落进对应动作卡的那个人的分区里。

## 落位不写死

技能**不预设**任何目录结构、称呼或人数。第一次用会先问清楚:卡放哪个文件夹、图放哪、教练怎么称呼、有几个人在练。答案记进**你项目的** `CLAUDE.md`,不写进技能本身——所以这个技能可以分享给别人,而你的目录结构和人名不会跟着跑出去。

## 边界

**不是医疗建议,不替代教练。** 每张卡的变式提醒里都写明「以你自己教练的做法为准」。涉及疼痛、伤病、康复,提示去看专业人士,不做诊断。动作规范各流派有分歧,卡上必须写清写的是哪一版。

不负责:只问健身知识或要训练计划**而不打算落盘**、算热量与营养成分(→ `nutrition-analyzer`)、找医生或理疗师(→ `care-scout`)、单纯画图表(→ `figure-forge`)、补剂调研(→ `supp-research`)。
