# 自绘示意图规格

每张动作卡自绘两张图，输出 SVG（可改）+ PNG（好贴）：

1. **动作示范图** `<动作名>示范.svg` —— 并排两到三幅关键位置，标出轨迹和参考线
2. **发力肌肉图** `<动作名>-发力肌肉.svg` —— 把发力的肌肉高亮上色

转 PNG：`rsvg-convert -z 3 -o out.png in.svg`（缺就 `brew install librsvg`）。

## 画法：填充轮廓 + 描边，绝对不要火柴棍

火柴棍图讲不清「哪块肌肉在哪儿」，用户会直接嫌弃。正确画法：

- **四肢**：加描边的粗圆头线条。同一段画两遍，先粗一点的描边色，再细一点的填充色：
  ```svg
  <path d="M 176 332 L 174 278" stroke="#c9ccd1" stroke-width="20" fill="none" stroke-linecap="round"/>
  <path d="M 176 332 L 174 278" stroke="#eceef1" stroke-width="17" fill="none" stroke-linecap="round"/>
  ```
  **按由后到前的顺序逐段画**（每段都是描边+填充成对），这样重叠处才有轮廓、分得开层次。
- **躯干**：填充路径（正面/背面观）或粗圆头胶囊（侧面观，从髋画到肩，`stroke-width` 32 左右）
- **头**：椭圆 + 一个小三角当鼻子指示朝向
- 身体填充 `#eceef1`，描边 `#c9ccd1`；手臂可以用略深的 `#dfe2e6` 与躯干分开

## 颜色约定（全库统一，跨卡一致）

| 颜色 | 含义 |
|---|---|
| 红 `#d64545` | 主动肌 Primary |
| 青 `#14b8a6` | 协同肌 Secondary |
| 灰蓝 `#7a8794` | 稳定肌 Stabilizer |
| 灰 `#c9ccd1` | 要它别出力的代偿肌 |
| 紫 `#8b5cf6` | **被拉长的肌肉**（只在柔韧性 / 活动度类动作里出现） |

肌肉块用 `fill-opacity` 0.75~0.8，配同色系深一点的描边。图例放画布底部，逐条写清。

## 参考线要画

示范图的价值一半在参考线上，它把「感觉」变成「看得见的标准」：

- 深蹲：**脚心正上方那条青色竖虚线**（杠铃全程不能离开它）、**髋膝水平线**（看得出髋有没有低于膝）
- 靠墙滑行：沿墙的滑行轨迹箭头、到顶推离墙面的箭头
- 通则：凡是教练会用嘴说的空间关系，都该有一条线

**参考线画在人体之上**（最后画），否则会被身体挡住看不见。

## 版面

- 画布宽 680，`viewBox="0 0 680 H"`，无负坐标
- 两幅并排：每幅 306 宽，`x=24` 和 `x=350`，`rx=8` 浅色边框
- 底部一条分隔线 + 「要点 key points」两列中英双语条目
- 字号只用两级：12px（中文条目、面板标题）、10~11px（英文注释、引线标签）
- 面板标题放**每幅图下方居中**，别放左上角——左上角常和图内标注打架

## 自包含（必须）

SVG 会被 `rsvg-convert` 在页面 CSS 之外渲染，所以：

- 根元素写显式 `font-family="-apple-system, 'PingFang SC', 'Helvetica Neue', Arial, sans-serif"`，
  没有 PingFang SC 中文会变豆腐块
- 每个 `<text>` 显式 `font-size` 和 `fill`
- 根 `<svg>` 同时写 `width`/`height` 和 `viewBox`
- 第一个子元素是白色背景矩形
- 加 `role="img"` 与 `<title>`/`<desc>`

## 渲染后必须目视检查

标签重叠和溢出画布是最常见的翻车，实测改了三轮才不打架。渲染成 PNG 后看一遍：

- 有没有两段文字叠在一起
- 有没有文字超出面板边框或画布右边缘（中文按每字约等于 font-size 的宽度估算，
  英文按 0.5~0.55 倍估算，算完再留 20px 余量）
- 参考线有没有被身体挡住
- 引线有没有横穿人体

发现问题就改坐标重渲，别将就。

## 图注必须交代边界

每张自绘图下面跟一行图注，写明：

- 来源和源文件路径（SVG 留着，方便以后改）
- **画了哪几块、没画哪几块**（协同肌稳定肌常常不画，得说一声，否则用户以为漏了）
- 声明「位置形状是示意，精确解剖以旁边的真解剖图为准」——自绘图不该冒充解剖学权威
