# 动作卡规格

一张卡分两半，中间用 `---` 硬切开：

- **上半 = 客观知识**，练这个动作的所有人共用
- **下半 = 各人记录**，按人分区

模板见 `assets/card-template.md`。

## 上半张的固定顺序（不要改动）

```
一句话（abstract 提示块）→ 跳转行 → [安全块] → 动作示范
→ 练到哪些肌肉 → 通用常见错误与代偿 → 变式提醒 → 相关动作
```

**先讲怎么做，再讲练到哪。** 这是人翻卡的真实顺序。
把肌肉放在动作示范前面是倒的——用户第一反应是「这动作怎么做」，
不是「这动作练哪块肌肉」。

### 1. 一句话

用 `> [!abstract]` 提示块提到最上面。frontmatter 在 Obsidian 里会渲染成属性面板，
信息密度低，一句话必须紧跟其后，让人一眼看到最要紧的判断。

内容三样：**是什么动作、做对了什么感觉、做错了会变成什么样**。
末尾点明训练性质，并给一句该性质的实操含义（矫正类写「加重量没有意义」，
力量类写「强度表要认真记」）。

### 2. 跳转行

`各人记录直接跳 → [[#某人]]`，练的人多了就并排列出。
Obsidian 的 `[[#标题]]` 支持同文件内跳转，点一下到自己那段。

### 3. 安全块（条件性）

**只有有重量或有摔倒风险的动作才加**，徒手和矫正动作不加，别硬凑。

放在**动作示范之前**，因为读的人可能直接照着做。三件事：
器械怎么设置、**做不动了怎么脱身**、什么情况别练。

脱身那条要具体到动作，并且加一句「上重量前先空手把这个脱身动作练一遍，
真出事时是没时间思考的」。

### 4. 动作示范

自绘示意图 + 编号步骤。**需要器械的分「器械设置」和「动作本身」两段**：
出杠、退几步、挂钩高度这类细节新手最容易忽略，也最容易受伤。

组数次数一律写「以教练给的为准」，不要照搬网上的处方。

### 5. 练到哪些肌肉

**每张卡都留三个词的解释**（主动肌 / 协同肌 / 稳定肌），别假定读的人懂。
其中稳定肌那条要写清关键：**它们偷懒的结果不是动作做不动，而是动作变形**。

然后一张分工表，四列：角色 / 哪几块 / 分量 / 在这个动作里干嘛。
最后一列不能省——「三角肌前束」放在那儿没意义，
「帮着抬手臂，同时把肱骨头稳在肩窝里」才有意义。

肌肉名一律双链到肌肉名称对照表的对应小节。

图放两类：自绘发力图（讲清谁在干活、什么关系）+ 真解剖高亮图（讲清长在哪）。
两类互补，别互相替代。

### 6. 通用常见错误与代偿 ★

**这是整张卡最值钱的部分。** 光写「别耸肩」没用，必须五列：

| 错误现象 | 谁在代偿 | 你会感觉到 | 说明哪块偷懒 | 怎么改 |

三个核心问题：**谁替你干了活、身上哪儿有感觉、这说明哪块弱**。
有了这三列，用户凭身体感觉就能自己反查，不用等教练开口。

表下面跟一个 tip 块讲用法，重点是：
**同一个代偿反复出现，第四列那块就是薄弱环节，值得单独找动作补。**
这比笼统地「多做几次」有效得多，也是这套卡能产生复利的地方。

### 7. 变式提醒

单独小节 + `> [!warning]` 块。说清这张卡写的是哪个流派版本、别的版本差在哪，
并强调**以用户自己教练的做法为准**。

这条不是客套。同一个动作各流派做法差别可能很大（深蹲的高杠低杠、
靠墙滑行的前臂贴轴还是手掌压轴），写死一种会误导。

## 一个动作有多种练法：拆卡还是写进变式提醒？

同一个动作名下常有几种做法。**判据不是「差别大不大」这种感觉，而是 frontmatter 会不会打架。**

frontmatter 是**单值**的：`主肌群`、`训练性质`、`肌群/` 标签各只能填一套。
所以三问：

1. **主动肌变了吗？**
2. **训练性质变了吗？**
3. **肌群标签变了吗？**

**任一为「是」→ 拆成两张卡。** 硬塞进一张，frontmatter 必有一半是错的；
更糟的是**标签检索会骗人**——点 `#肌群/竖脊肌`，出来一张其实在练臀的卡。

**全为「否」→ 同一张卡的变式提醒。** 只是难度、杠杆、器械型号、握法、负重方式不同，
练的还是同一套肌肉，拆了是重复劳动，改一处要改两处。

实例对照：

| 变式 | 主动肌变了吗 | 结论 |
|---|---|---|
| 山羊挺身：髋铰链版（练臀腿）vs 脊柱屈伸版（练竖脊肌） | **变了** | 拆 |
| 深蹲：高杠 vs 低杠 | 没变，只是比例挪几分 | 不拆 |
| 山羊挺身：45° 罗马椅 vs GHD | 没变，杠杆变长而已 | 不拆 |
| 靠墙滑行：前臂贴轴 vs 手掌压轴 | 没变 | 不拆 |
| 引体：正手 vs 反手 | 没变（反手多吃点二头，程度差异） | 不拆 |
| 硬拉：传统 vs 直腿 / 罗马尼亚 | **变了**（股四头参与度质变、髋主导程度不同） | 拆 |

### 拆的时候：只写差异，别复制

变式卡**只写不一样的部分**：一句话、分工表、这一版独有的代偿和安全事项。
器械设置、通用代偿、相关动作这些共享内容**双链回主卡**，不重复誊写。
两张卡互相链接，各自的 frontmatter 才能都是准的。

### 不要预先拆

**没人练的那一版，先只在变式提醒里留一段说明**，等真有人要练了再开卡。
否则库里会堆一批没人看、也没人维护的空壳卡。

拆卡前**先问用户**，别自作主张改他的库结构。

## 下半张：各人记录

每人固定四小节，顺序永远一样，翻起来不用重新找：

1. **为什么练 / 状态** —— 教练为什么给他开这个动作。半年后翻回来全靠这行。
   康复矫正类要写清缘由；停练了把状态改成已停并写原因，**不要删卡**
2. **当前强度** —— 表格，带更新日期，最新在上，**历史行保留不删**（看得出进步曲线）
3. **教练提点** —— 列表不用表格（教练一句话有时要写三行，表格挤不下），
   每条开头加粗绝对日期，最新在上
4. **自查清单** —— 复选框，从反复出现的提点里提炼

**谁练谁开区，不预留空壳。** 一个人都没有就写一句「还没有人开区」。

## frontmatter

`type / 中文名 / 英文名 / aliases / 部位 / 训练性质 / 器械 / 主肌群 / 练习者 / tags / created`

- **文件名双语** `中文名 English Name.md`，Obsidian 搜索是子串匹配，中英文都能搜到
- **aliases 把常见叫法都列上**（英文全称、缩写、中文俗称），
  否则同一个动作会因叫法不同分裂成好几张卡
- **部位必写**，只写肌肉名普通人看不懂
- **主肌群把主动肌都列上**，别只写一块

## 建卡时的自检

- [ ] 一句话在最上面，不是埋在中间
- [ ] 顺序是「先怎么做，再练哪儿」
- [ ] 三个词的解释留着
- [ ] 代偿表五列齐全，中间三列都填了
- [ ] 有重量的动作有安全块，徒手的没有多余的安全块
- [ ] 肌肉名都双链到对照表，对照表里没有的已补齐并登记署名
- [ ] 三个轴的标签都打了，肌群标签只给主动肌
- [ ] 自绘图渲染后目视检查过，没有重叠溢出
- [ ] 变式提醒里写了「以你自己教练为准」
