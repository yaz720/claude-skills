# LabReader — 读报告(检测报告解读)

## 概述

本技能把用户手上的检测报告(照片 / PDF / 粘贴的文字)变成一份**系统化的中文解读报告**。它回答的是「这份报告说了什么、哪些值得在意、下一步问谁」,**不回答**「所以该怎么治」——那是 second-opinion-panel 的事。

**产出物的定位(最重要的一条)**:输出的是**解读功课与就诊准备材料,不是诊断,不是医疗建议**。本技能不下诊断、不排除诊断、不建议开始或停止任何治疗;它的价值是让用户看懂自己的报告、带着对的问题去见医生。

覆盖范围:血液/尿液/便检化验单、影像报告文字(MRI/CT/超声/X光/钼靶)、心电图、骨密度 (DEXA)、肺功能、病理报告(配硬红线,见安全红线)。**基因检测报告不在范围内**(23andMe、携带者筛查等),遇到明说并建议咨询遗传咨询师。

## 隐私(动手前先看)

- **上传段(技能管不了,提醒用户)**:报告一旦进入对话就已离开用户设备。若用户发来的报告**带着姓名/病历号抬头**,在解读开头**顺带提一句**:下次拍照可遮住抬头,不影响解读——说一次就够,不说教、不拒绝干活。
- **提取即脱敏(技能的硬承诺)**:落盘的解读报告里**只进**医学内容 + 年龄段、性别、检测日期。姓名、病历号、身份证号、条形码号、住址电话、机构名称与联系方式,**一概不写入任何产出**。机构需要指代时用"送检实验室"等泛称。

## 红旗筛查(前置,不可跳过)

解读前先扫一遍**危急值 (critical values)** 与急症描述。出现以下任一类,把「立即联系医生/就医」放在输出最前面,解读退居其后并从简:

- 化验危急值:如血钾 >6.0 或 <2.5 mmol/L、血糖极端值、血红蛋白/血小板极低、肌钙蛋白 (Troponin) 升高、INR 显著超治疗窗等(以通行危急值清单为准)
- 影像急症字眼:急性出血、夹层 (dissection)、大面积栓塞、气胸、占位伴压迫等
- 报告本身标注的"危急值已电话通知"字样

**宁可误报,不可漏报。** 既往旧报告里的已处理事件不触发中止,作为背景纳入。

## 解读引擎(六步)

### 1. 摄取与全量提取

- 逐项提取:指标名(中英对照)、结果、单位、实验室参考区间、标注(↑↓/H/L)。**全量,不是只挑异常项**——正常项里藏着信息(贴着下限、或与其他指标组合才有意义)。
- 顺手收集**采样条件**:是否空腹、采样时间、近几天有无剧烈运动/饮酒/感染、在服药物与补剂(生物素!)。用户没说就问一次,问不到按未知处理并在报告里声明。
- 单位要核对:国内外单位制不同(mg/dL vs mmol/L 等),换算后再比区间,别拿数值直接套错单位的区间。
- 照片看不清的项**如实标"无法辨认"**,不猜、不填充。

### 2. 三层参考区间

对每个值得展开的指标,分三层说清,**不混为一谈**:

| 层 | 是什么 | 注意 |
|---|---|---|
| 实验室区间 | 报告纸上印的范围 | 只是"95% 送检人群落在这里",不是"健康范围" |
| 最优区间 | 有证据支持的更优目标(如维生素D、铁蛋白、空腹胰岛素、TSH) | **必须注明证据强度与争议度**,功能医学式的激进区间要如实标注其争议 |
| 人群修正 | 族裔、年龄、性别、绝经前后、孕期、肌肉量(对肌酐)等 | 延续家族的族裔加权思路:东亚人群的专项区间/证据要专门查 |

### 3. 假异常甄别(检测层解释先行)

身体层解释之前,先排除检测层解释,这一步是对抗恐慌化的第一道闸:

- 溶血 → 血钾、LDH、AST 假性升高;非空腹 → 血糖、甘油三酯;剧烈运动 → CK、ALT、肌酐;脱水 → 肌酐、血细胞比容;生物素补剂 → 甲功、肌钙蛋白免疫法干扰;采样时间 → 皮质醇等昼夜节律指标;近期感染 → 白细胞分类
- 写法:「这个值的升高有 X 种检测层解释,你的情况符合哪种;若排除,身体层的可能性才轮到 Y」。
- 有检测层嫌疑的指标,标准动作是**建议按正确条件复查一次**,而不是直接展开疾病解读。

### 4. 分级与组合解读

- 每项给**红/黄/绿**分级:红=尽快就医;黄=值得写进就诊问题清单或近期复查;绿=本次不用管。**贴线值单独一档说**(在区间内但贴边,值不值得看趋势)。
- 分级对抗两个方向的失真:恐慌化(谷歌单个指标吓自己)与轻描淡写("都在范围内"完事)。绿≠保证没事,红≠一定有病,措辞上都别越界。
- **组合解读**:单指标孤立看会漏掉的模式要主动拼——铁四项(铁蛋白+血清铁+转铁蛋白饱和度+TIBC)、肝酶组合(ALT/AST 比值、GGT、ALP 的分工)、甲功(TSH+T4/T3 的组合方向)、肾功能(肌酐+eGFR+尿素氮)、血常规模式(三系分别看)、血脂(非 HDL-C、必要时提 ApoB)。

### 5. 影像与专科报告解码(化验单之外的独特价值)

- **对冲措辞词典**:放射科报告是一门对冲语言。unremarkable(没发现值得说的=好话)、grossly normal、cannot exclude(不能排除≠怀疑,常是免责措辞)、clinical correlation recommended / 请结合临床(标准结尾套话)、"建议随访"(区分套话与真提示)。逐句把对冲语言翻译成大白话。
- **偶发瘤 (incidentaloma) 焦虑校准**:甲状腺结节、肺小结节、肝/肾囊肿、垂体微腺瘤等,给**真实流行率**(如小甲状腺结节在成年人中极常见)+ 对应**标准分级与随访路径**(TI-RADS、BI-RADS、Fleischner、PI-RADS、Bosniak),让用户知道自己落在路径的哪一格、下一格是什么。
- 心电图:机器自动判读假阳性常见,明说"以医生复核为准"。
- **病理报告(硬红线)**:只做三件事——解释每个术语、解释分级/分期体系是什么(如 Gleason、免疫组化标记的含义)、指出报告里哪些字眼是关键。**绝不做良恶性方向的独立判断**;出现恶性/可疑恶性字眼,固定动作:建议尽快面见医生 + 值得开一场多学科会诊 (second-opinion-panel)。

### 6. 跨期对比(用户提供了历史报告时)

- **无状态**:本技能不保存任何历史;想看趋势,用户把旧报告一起给。
- 同指标拉时间线,趋势常比单点重要(eGFR 缓降与单次偏低是两码事;肿瘤标志物看动态)。
- **方法学警告**:不同实验室/不同方法的数值不完全可比,跨实验室的趋势要降权解读。

## 报告结构

保存为 Markdown 文件,文件名 `检测报告解读_{检测日期}.md`。中文撰写,指标与术语首次出现附英文,如 铁蛋白 (Ferritin)。

```
# 检测报告解读({检测日期})
## 一、报告概况与采样条件(含未知条件声明)
## 二、红旗项(无则明写"本次未发现需紧急处理的项目")
## 三、逐项全量表(指标/结果/单位/实验室区间/分级/一句话解读)
## 四、值得展开的发现(黄级以上逐个:三层区间、假异常甄别、组合解读、机制大白话)
## 五、影像/专科报告解读(如有;逐句解码+分级体系定位)
## 六、跨期趋势(如提供历史报告;附方法学警告)
## 七、就诊问题清单与指路(可直接带去诊室的问题;该挂什么科)
## 八、参考文献(编号与正文 [n] 对应,附 URL)
## 免责声明
```

免责声明固定内容:本报告为信息解读,不构成诊断或医疗建议;所有结果请以医生的判读为准,任何治疗决定请与医生讨论。

## 证据与引用规则

- 来源优先级:专业学会指南与分级体系(ACR、ATA、KDIGO、Fleischner Society 等)> 权威临床参考(Mayo Clinic、NIH/MedlinePlus、大型实验室参考手册如 Labcorp/Quest、UpToDate 式综述)> 其他。内容农场与保健品营销内容不作为依据。
- "最优区间"必须给来源并标注证据强度;人群修正要专门搜(`{指标} reference range Asian/East Asian`、该地区学会标准)。
- 具体数字(流行率、恶性率、随访间隔)须有来源并用 [编号] 标注;基础生理常识可用自有知识,不伪装成引用。
- 找不到的写"未找到",不推测填充。

## 安全红线

- 不下诊断、不排除诊断;所有结论落在「与医生确认」上。
- 病理报告按第 5 步硬红线执行;重大字眼绝不淡化也绝不加戏。
- 危急值按红旗流程,就医指引优先于解读。
- 不据报告建议用户自行开始/停止/调整任何用药——发现用药相关问题,写进就诊问题清单;想做选药功课指向 rx-scout。
- 对抗恐慌化的同时不过度安抚:绿级的准确表述是"本次报告未见异常",不是"你很健康"。

## 输出前自检

- [ ] 红旗筛查做过;有红旗时就医指引在最前
- [ ] 逐项全量表覆盖了报告上**每一个**能辨认的指标,看不清的标了"无法辨认"
- [ ] 产出中无姓名/病历号/证件号/条码/机构名(提取即脱敏)
- [ ] 黄级以上每项都过了:三层区间(最优区间标了争议度)、假异常甄别、组合解读
- [ ] 影像/病理:对冲措辞逐句解码;偶发瘤给了流行率与分级路径;病理未做良恶判断
- [ ] 有就诊问题清单、指路(挂什么科)、免责声明;全文无诊断式断言
- [ ] 引用编号与文献一一对应,数字都有来源
