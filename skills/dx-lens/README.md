# dx-lens(检测报告解读)

> **状态:🚧 开发中**(触发与能力基线均未跑;评测用例起草中,跑通并达 `bar.yaml` 线后再转 ✅)

一个 Claude Code **技能**:把你手上的医学检测报告——化验单、MRI/CT/超声/X光报告、心电图、骨密度、肺功能、病理报告——变成一份**系统化、脱敏的中文解读报告**(Markdown),而不是"挑两个异常项讲讲 + 请咨询医生"。

## 为什么值得装(模型裸答不会自己做的部分)

- **逐项全量,不只讲异常**:正常项里藏着信息——贴着下限的值、连着几年在挪的值、要和别的指标拼起来才有意义的值。
- **三层参考区间分开说**:化验单上的"参考范围"只是实验室区间;之外还有注明争议度的最优区间、和族裔/年龄/性别/绝经的人群修正——三层混为一谈是常见误读来源。
- **先排检测层解释,再谈身体层**:溶血、没空腹、运动后、生物素干扰……很多"异常"其实是采样问题,标准动作是按正确条件复查,不是直接吓自己。
- **影像报告的对冲措辞解码**:unremarkable、cannot exclude、"建议随访"到底哪句是套话哪句是真提示;甲状腺结节、肺小结节这类偶发发现,给真实流行率和 TI-RADS/Fleischner 等标准随访路径,让你知道自己落在哪一格。
- **红黄绿分级**:哪些尽快就医、哪些值得写进就诊问题、哪些本次不用管——同时对抗恐慌化和轻描淡写。
- **跨期趋势**:把历史报告一起发来,同指标拉时间线;趋势常比单点值重要。
- **产出天生脱敏**:解读报告只含医学内容 + 年龄段/性别/日期,姓名、病历号、机构信息一概不写入。

## 边界

- **不下诊断、不排除诊断**;产出是就诊准备材料,一切以医生判读为准。
- 病理报告只解释术语与分级体系,**不做良恶性判断**;基因检测报告(23andMe 等)不在范围。
- 要治疗方案或多方意见 → `second-opinion-panel`;该挂什么科/找医生 → `care-scout`;选药 → `rx-scout`;补剂 → `supplement-scout`。
- 报告上传进对话即离开你的设备;在意的话拍照时遮住姓名/病历号抬头,不影响解读。
