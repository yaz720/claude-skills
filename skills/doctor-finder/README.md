# 找医生 (doctor-finder)

> **状态:🚧 开发中**(触发基线 21/22,trig-002 一条待修;4 条能力用例已写好、尚未实跑判分,补齐后再转 ✅)

一个 Claude Code **技能**:**把「我有个健康问题」端到端变成「选对从业者、并且约得上」。**

重点不在"搜出一个医生"——普通搜索就能给你一串名字和星级。重点在**普通搜索给不了的那部分**:这位医生**真正**擅长什么(而不是科室模板列表写了什么)、几个平台上性质完全不同的分数该怎么分开读、差评里哪些是反复出现的模式、你的保险到底能不能直接约。

## 这个技能做什么

- **需求评估**:分步问清症状/年龄/急慢性/是否涉及鉴别诊断,并主动问**风格偏好**(高效型 / 耐心倾听型 / 细心解释型 / 爱琢磨型、保守 vs 积极)——这一项决定了后面拿什么去匹配
- **从业者类型推荐**:MD/DO、NP/PA、PT/OT/SLP、精神科 vs 心理师 vs 咨询师、RD vs nutritionist……先判断"该找哪一类人",再找具体的人
- **判断真实亚专长**(核心方法论,见下)
- **跨平台评分交叉解读**(核心方法论,见下)
- **系统化负面评价分析**:按主题归类差评——等待时间 / 沟通被催促 / 诊断失误 / **账单问题**(美国就诊高频投诉)/ 前台态度,并区分"偶发投诉 vs 反复模式"、"医生本人问题 vs 诊所体系问题"
- **保险与转诊导航**:PPO 可自行约专科、HMO 需 PCP 转诊,以及 in-network 与 prior authorization 的确认点
- **可直接用的预约话术**:中英双版,含要确认的问题(是否 in-network、是否接新患者、诊所能否做该项检查、就诊前是否需停药)+ 就诊前准备清单

## 两条核心方法论

技能的价值主要在这两条上——它们正是"随手搜一下"最容易搞错的地方。

### 1. 机构页面的"可治疗疾病"列表基本没有参考价值

那是**整个科室的通用模板**,不是这位医生的个人专长。(某皮肤科医生页面同时列着尿布疹、摇篮帽和麻风病——一眼就知道是菜单。)

判断真实专长要按可靠性排序取信号:**WebMD 诊疗频率数据**(基于实际理赔记录,"treats X more than most providers",最硬的客观指标)> Healthgrades "treats most frequently" > 医生**本人填写**的 Special Interests > Fellowship 训练 > 论文与学术演讲 > Google 评价的**文字内容**。机构标签列表和诊所服务清单排在最后,基本不用看。

还有一条反向提醒:有些病就是该专科的**常规操作**,不存在"专家"一说(皮肤科看灰指甲、家庭医生看高血压)。这时候技能会主动告诉你别浪费时间找"最好的专家",转而去看经验年限、是否愿意做检测确诊而非经验性开药、是否会跟进疗程。

### 2. 两类评分性质完全不同,不能混着看

- **医疗体系内部评分**(如 Sutter 的 815 份患者调查):样本大、标准化、覆盖全部就诊患者,统计上可靠——但**几乎没有文字细节**,且分数普遍偏高、区分度低。只能用来确认"这位医生没有系统性问题",**不能**用来判断专长或匹配度。
- **Google / Yelp**:样本小、自愿提交、有幸存者偏差——但**文字内容丰富**,能看出具体治好了什么、沟通风格、诊所实际怎么运作。判断匹配度**主要靠这个**。

所以:内部评分 5.0 ≠ 适合你。两类分数**并列呈现**,但用文字内容做匹配判断。同一位医生跨平台分数打架是常态(Google 5.0 而 Sharecare 1.7),如实列出、让你自己判断,不挑好看的报。

## 覆盖范围

各科医生(MD/DO)、家庭医生(PCP)、儿科/妇产/骨科/皮肤/眼/牙、物理治疗师(PT/DPT)、职业治疗师(OT)、语言治疗(SLP)、脊椎(DC)、针灸(LAc)、足病(DPM)、精神科/心理咨询、注册营养师(RD/RDN)、正畸、NP/PA,以及有康复背景的普拉提/瑜伽教练。

面向**美国**就医环境(保险网络、转诊规则、评分平台均按美国体系设计)。

## 边界

**不做医学诊断。** 可以建议看哪一类医生、解释某项检查是干什么的,但会明确说明这不是诊断;紧急情况直接 911 或急诊。没验证过的事(比如某诊所能不能做某项检查)会直说没验证,并给出你可以自己打电话确认的具体问题。搜索查询里不会带上你的个人健康细节。

不负责:纯医学知识科普、解读体检报告、算热量做食谱(→ `nutrition-analyzer`)、补剂选购(→ `supp-research`)、食材对比(→ `food-research`)、画图(→ `figure-forge`)。
