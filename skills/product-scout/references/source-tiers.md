# 来源分级与品类数据库地图

## 来源分级(推荐依据只认 T1/T2;T3 只进候选池;T4 不用)

| 级 | 是什么 | 例 | 用途 |
|---|---|---|---|
| **T1 数据库/一手数据** | 逐成分/逐参数、可核验、无推荐立场 | EWG Skin Deep、INCIDecoder、CosDNA、官网成分页/规格页、FDA/CPSC 召回库、法院诉讼记录 | **逐项核验的依据**,推荐必引 |
| **T2 严格第三方** | 买样实测/系统评审、无联盟佣金或有明确防火墙 | Consumer Reports(与 MadeSafe 合作款)、RTINGS、Project Farm、学术综述(如 Int J Cosmetic Science)、Cochrane/临床对照研究 | 实测表现与机理结论 |
| **T3 商业媒体榜单** | 编辑精选+联盟链接驱动 | Wirecutter、NBC Select、Forbes Vetted、品牌博客 | **只用来收集候选名**,内容一律不作依据 |
| **T4 不可用** | 无法溯源或利益即内容 | 品牌自述"最温和"、带货文、AI 聚合站 | 不引用 |

**识别 T3 的方法**:URL 带 affiliate 参数、文内"我们可能获得佣金"声明、"best X 2026" 标题体、每个产品配购买按钮。

## 品类 → 数据库/严格第三方地图

| 品类 | 逐项核验数据库 (T1) | 严格第三方 (T2) | 该品类的"两道关"提示 |
|---|---|---|---|
| 个护(洗发水/护肤/牙膏) | INCIDecoder、EWG Skin Deep、CosDNA | CR×MadeSafe、皮肤科学术综述 | 认证管毒性,不管刺激性;表活/酸类要另查档位 |
| 清洁用品 | EWG Guide to Healthy Cleaning、成分表 | CR | 同上;"plant-based"不等于温和 |
| 家电(净化器/吸尘器/厨电) | 官方规格页(CADR/分贝/功率)、Energy Star 库、CPSC 召回库 | RTINGS、CR、Project Farm | 参数宣称 vs 实测值常有差;安全认证(UL/ETL)≠性能 |
| 数码 | 官方规格、FCC ID 库 | RTINGS、NotebookCheck | 跑分≠体验;够用即最优最常在这翻车 |
| 家具(桌椅/床垫) | 材质申报(CARB Phase 2/TSCA Title VI 甲醛、CertiPUR-US 泡棉)、承重规格 | CR、BIFMA 认证 | 板材甲醛与结构承重是两道关 |
| 母婴 | CPSC 召回库、材质(BPA-free 只是起点,查具体塑料号/硅胶级别)、JPMA | CR、Lullaby Trust 类 | 召回史必查;"婴儿专用"是营销词不是标准 |
| 工具 | 官方规格(扭矩/电池平台) | Project Farm(实测拆解)、Torque Test Channel | 电池平台锁定是隐性成本 |

## 通用核验动作清单

1. 完整成分表/规格表入手(数据库或官网,拒绝转述)
2. 风险名单比对(该品类的涉诉/召回成分,如个护的甲醛释放型防腐剂)
3. 认证核验:认证的**范围**是什么(毒性?能效?结构?),没盖到的维度单独查
4. 宣称分级:公布数值 > 有认证宣称 > 无数据宣称;无数据宣称给用户自验方法
5. 诉讼/召回搜索式:`<brand/ingredient> class action`、`<product> recall CPSC/FDA`

## 已知陷阱(实战收录)

- **raw 榜单陷阱**:媒体榜单的"编辑实测"多为公关样品+联盟佣金结构,同一榜单不同年份推荐大换血
  往往跟随佣金率而非产品变化
- **认证遮蔽**(2026-09 洗发水实战):EWG Verified 的 ATTITUDE 用 Sodium Coco-Sulfate(SLS 同类)
  ——认证只审毒性名单,强刺激表活照样过;"天然来源"宣称同理(来源不决定性质,分子结构才决定)
- **贵价≠温和**(同上):$48 植村秀 Muroto Volume 是 SLES 体系,与 $6 药妆同档;
  溢价买的是香氛/质地/品牌,不是主功能
- **宣称≠数据**(同上):"pH balanced" 是宣称,"pH 5.0-5.5" 是数据;两者在报告中必须区别标注
