# product-scout

> **状态:🚧 开发中**(触发基线 11/12 达标、负例 6/6 全过,已知失手:家电+宠物场景 trig-005;能力用例 2 条 pending,待实战产出后跑基线,补齐后再转 ✅)

一个 Claude Code **技能**:把"我要买个 X"(洗发水、工作桌、净化器……)端到端变成
"选定一个**经过逐项核验**的具体产品"。

**差异化价值**——模型裸答会热心地转述几个购物榜单;它不会自己做的是:

- **来源分级**:把带联盟佣金的商业榜单降为"仅候选池",推荐依据只认严格第三方
  (Consumer Reports 类)+ 成分/参数数据库(EWG Skin Deep、INCIDecoder、RTINGS 等)
- **逐项核验**:每个推荐产品的完整成分表 (INCI) / 规格表逐项过档位表,没核过的不出手
- **双重关卡**:安全认证只管毒性、不管刺激性/适用性——两道关分开审
  (实战抓过反例:EWG Verified 产品用着 SLS 同类表活)
- **卖点机制审查**:每个附加卖点(蓬松/抗菌/静音)先问"靠什么实现",
  靠可疑添加或无证据宣称实现的扣分
- **够用即最优**:超出需求的性能不是白送——化学品类过剩的清洁力全部转化为刺激
- **第一性原理拆解**:先回答"这个品类最少需要什么",再判断哪些成分是核心、哪些是营销
- **敢于推翻自己**:核验与初版结论冲突时公开降级并说明(这个动作本身就是可信度)

诞生自 2026-09 一次真实的洗发水调研:v1 按媒体榜单推了 $48 的 SLES 体系产品,
被用户的方法论质询推翻后重做,v2/v3 的全套做法沉淀为本技能。

## 这个技能做什么

- 买前调研:个护、清洁、家具、家电、工具、数码、母婴等一切实体消费品
- 产出:判断框架(教你这个品类怎么挑)+ 逐项核验的推荐名单 + 明确不推荐名单 + 可维护的追踪表

## 边界

- 食品食材 → food-research;营养补充剂 → supplement-scout;药品 → rx-scout
- 找本地服务商(搬家/修车/驾校)→ service-scout
- 餐厅/景点推荐、纯成分知识问答:不触发
